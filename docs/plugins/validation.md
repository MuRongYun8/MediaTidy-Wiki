# SDK v2 验证记录

验证日期：2026-10-21。本文只记录 SDK v2 基础建设；旧 AI 模板的模型诊断及发布记录不作为本轮验收依据。

## 已通过

- 主后端 `go test ./... -count=1`，以及插件、AI、通知、文件路由、任务队列、迁移、handler、整理服务的针对性回归。
- 独立 Goja 工作进程、SDK 开发包与协议一致性；真实 Goja 执行目录扫描、释放进程、完成回调、分页读取结果和持久化报告。
- 调度、持久任务与事件的权限、修订、重叠、暂停、取消、重启及去重回归。
- 存储的安装实例隔离、CAS、TTL、事务、配额、备份恢复、残留数据和清理边界。
- 文件引用与操作、方案修订及整理确认、HTTP 限制、带标记的模拟 FF 数据隔离回归。业务服务使用模拟数据，不需要真实凭据。
- 前端生产构建、独立预览构建，以及 26 项前端状态、目录、配置和预览测试。
- SDK 合约生成校验、mock 与 CLI 测试；starter 类型检查、构建、宿主包校验和 5 个真实 Goja 场景。
- 真实浏览器中的通用结果表：100 条数据、每页 20 条、全选本页、跨页选择和无运行时错误。页面数据使用模拟宿主。
- 开发文档的本地链接检查、开发 Skill 的结构校验。
- 插件中心空列表、空发现目录和空仓库输入，宿主不再提供内置示例安装入口；下载接口要求登录，返回完整 Skill ZIP。
- 官方 Wiki 的插件导航、12 个文档页面和 Skill 静态下载通过 VitePress 构建；真实浏览器验证 Wiki 导航和下载，插件中心下载内容与 Wiki 文件一致。
- 插件中心桌面、390px 手机深浅主题和 Wiki 手机页面通过浏览器检查；界面使用模拟 API，不修改本机授权。

最终同步顺序为：生成类型 → 构建 starter → 同步文档与 Skill ZIP → 同步官方 Wiki → 检查生成物及 Goja 完成回调。目录清单仅是开发示例，不嵌入宿主。旧 AI 模板同步脚本已停用。

## 验证边界

尚未以真实模型、云盘、远程 FF 服务或外部通知验证业务可用性；模拟测试不代表这些服务已通过实测。管理界面与真实部署数据的完整安装、授权、调度和恢复流程仍需在测试部署中验收。

本轮未执行正式 Docker/garble 发行构建和只读容器部署验证；不以 Windows 本地测试替代正式环境验证。未发布远程模板或 npm 包，也未自动修改本机插件授权。

SDK v1 数据保留但不自动迁移、授权或执行。MT 主版本号和已有发布变更不属于本轮修改范围。
