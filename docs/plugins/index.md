# MT 插件开发文档 · SDK v2

插件使用 MT 提供的文件、媒体业务、任务、定时、外部服务和存储能力。作者提供业务脚本、页面协议和 Logo；MT 管理运行进程、组件渲染、权限和整理确认。

本文档与 SDK `2.0.0` 一起分发。`sdkVersion` 是字符串 `"2"`，页面协议版本仍为 `"1"`。SDK v1 插件保持数据但不能运行，不自动迁移权限。

完整签名以同包 `index.d.ts` 为准。MT 主仓库的 `backend/internal/plugins/contract/` 是协议唯一来源；生成器同时维护工作进程方法清单、类型与能力文档。修改宿主能力后运行 `node scripts/sync-plugin-sdk-v2.cjs`。

基础示例是**目录清单**：只读选择文件或目录 → 提交后台扫描 → 等待完成事件 → 保存业务数据 → 显示表格。它不依赖模型、TMDB 或真实云盘凭据。旧 AI 模板暂不作为 SDK v2 开发起点。

用户从插件中心安装后，需要检查能力及资源授权，配置并启用，再进入插件页面运行。定时与完成事件新建默认停用，由用户检查后启用。数据管理入口可查看使用量、业务键、运行历史、备份与卸载保留空间。

开发包包含独立预览资源与同版本 Goja 验证工具时，无需完整 MT 源码。源码构建开发包的方法见 [工具与验证](tooling.md)。本轮不发布 npm 包，不自动更新已安装插件。
