# 数据、配额与生命周期

插件业务数据位于 MT 主 SQLite 数据库的专用 `plugin_kv` 表，按宿主生成的安装实例 ID 隔离。数据库位置由 `DB_PATH` 决定，默认 `db/data.db` 相对进程工作目录。此物理位置仅供管理员备份运维，插件没有数据库、SQL 或数据库文件访问入口。

| 数据 | 归属和管理 |
|---|---|
| 业务键值 | `storage` API，数据管理页可查看、导出、恢复和清理 |
| 插件配置 | `config.get()` 读取，宿主按清单生成配置表单 |
| 第三方密钥 | 清单 `secrets` 声明，MT 加密保存；管理界面只显示设置状态 |
| 定时定义 | MT 统一调度记录 |
| 运行、结果、日志 | 专用运行记录，默认保留 30 天 |
| 授权、幂等、确认、事件与计量 | 宿主内部数据，清空业务存储不会删除 |
| 安装包 | 数据目录的 `plugins/packages`，包含代码、页面和 Logo |
| 插件写入授权目录的文件 | 用户文件，卸载或清空 storage 不删除 |

默认每安装实例 32 MiB、10,000 键；单值最多 256 KiB，单批最多 100 操作和 1 MiB。管理员可调整为 256 KiB–64 MiB、1–100,000 键。计量以 JSON 序列化后的 UTF-8 字节为准。键最长 256 字节，不能含控制字符或原型污染键。

```ts
const entry=mt.storage.get({key:'cursor'});
// found:false 表示不存在或已过期；found:true,value:null 是存在的 null。
mt.storage.set({key:'cursor',value:{page:2},expectedRevision:entry.revision || ''});
```

不提供 `expectedRevision` 为无条件写入；空字符串表示只能新建；提供修订号表示比较后更新。冲突返回 `CONFLICT`，读取当前值后由业务决定合并，不能无条件循环覆盖。

```ts
mt.storage.batch({operations:[
  {operation:'set',key:'cache/result',value:{ok:true},expiresAt:'2026-12-01T00:00:00Z'},
  {operation:'delete',key:'cache/previous'}
]});
const page=mt.storage.list({prefix:'cache/',limit:50,values:false});
const usage=mt.storage.usage();
```

一批操作共享事务，任何校验、冲突或配额失败都会回滚整批。`list` 按键排序，使用返回的 `nextCursor` 翻页；`values:true` 的一页还受 1 MiB 限制。TTL 读取即视为不存在，由宿主周期清理；普通键无限期保留。业务存储、运行结果和日志分别计量。

数据管理页在恢复前调用服务端预检来源、格式、容量与配置字段；正式恢复再次校验。恢复覆盖全部业务键及非密钥配置，停用插件并阻止并发写入。存在活动或结果未知的业务任务时拒绝清空/恢复，并列出任务。备份不含密钥、授权、任务确认和内部额度。备份文件上限 128 MiB。

同源更新/回退沿用安装实例。不同来源的同名插件不得继承空间和权限。卸载默认保留业务数据，重新安装后需核对来源并显式关联；关联后保持停用。不要把回退代码当成回退数据：自行保存业务格式版本，遇到不支持的版本停止写入，提示恢复备份或重置。MT 不执行插件提供的数据迁移脚本。

运行历史清理保留活动任务、待确认草稿和结果未知记录。已完成历史可过期清理，但幂等任务边界不会随业务键清空而消失。用户应在宿主任务中心核对结果未知的变更操作，不能通过删除键值强制重试。

密钥通过 `secrets.get({key:'apiToken'})` 读取当前插件声明且获准使用的第三方密钥。它是作者处理的敏感数据，不应写入 storage、日志或返回值。MT 使用独立主密钥加密，备份整个宿主时应安全保管主密钥；业务导出不会包含它。加密不承诺抵御部署机器最高权限持有者。

文件引用会复用同一文件版本。跨动作读取会延长引用租期；超过历史保留天数未使用、且安装没有活动流程或待确认草稿时，由宿主回收。引用不是永久路径书签，需要长期记住位置时保存授权目录 ID 与相对路径，再调用 `files.stat` 生成当前引用。每安装最多 20,000 个引用。

运行记录上限为每安装 2,000 条、宿主 10,000 条；完成动作同样计入。普通记录默认 30 天清理，活动和待确认记录不自动删除。任务列表按创建顺序分页，进度更新不改变分页顺序。完成事件正文按历史策略回收，去重键及变更操作的幂等记录继续保留。
